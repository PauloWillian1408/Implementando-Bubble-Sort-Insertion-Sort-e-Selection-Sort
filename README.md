# Implementação de Algoritmos ( Selection Sort, Bubble Sort e Insertion Sort )
Recebi um Trabalho na Faculdade da Matéria de Algoritmos e Complexidade, onde eu tive que implementar algoritmos de ordenação ( Selection Sort, Bubble Sort e Insertion Sort ). Tinha três desafios para fazer: o Fácil, Médio e Difícil.
# Desafio Fácil
- Implementar os três algoritmos ( Selection Sort, Bubble Sort e Insertion Sort ) em Python.

- Entrada:
- Um array gerado automaticamente de tamanho 10 com valores entre 1 e 50.

-  Saída:
- Array gerado e Array ordenado

# Desafio Médio
- Ordenação Decrescente:
- Adapte os três algoritmos para que ordenem os elementos do array em ordem descrescente.

- Tempo de execução:
- Use a Biblioteca time para comparar o tempo de execução dos três algoritmos para arrays de diferentes tamanhos ( 10, 100, 1000 elemnentos )

# Desafio Difícil 
- Analise de Performance em arrays Parcialmente Ordenados:

- Testar os Três Algoritmos em Três tipos de arrays:
- Totalmente desordenado
- Já ordenado
- Parcialmente ordenado ( ex: Só os 5 primeiros fora de ordem ).

- Observar qual Algoritmo se sai melhor em cada cenário.
